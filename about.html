I created this website in order to document my process in creating the various projects I’ve been working on. I wanted a place for my future self to look back on these projects so that I could later try to improve off of them or build off of them and get out of the dead ends I found myself in while working on them. It was upsetting to me, the idea that all this work I’ve put into these projects might mean nothing and all the thought that went into these will be forgotten, that there will be no explanation behind all the code I did. So I decided to make this website. I think it’ll be useful if I can write down my thoughts while I’m making the pages for my projects. It’s the same idea of rubber ducky debugging where you explain your code to a rubber duck in order to find the problem. If I can write down all of my thoughts, the direction becomes more clear.
